# Leave-Bot 🚂

Notifies a WhatsApp group **60 days before** every **long break** — 3 or more continuous days off (holidays + Sundays combined) — so everyone has time to book train tickets.

## How it works

- Holiday data lives in [data/holidays-2026.json](data/holidays-2026.json) (hand-verified from the office holiday list).
- Every day at 9:00 AM IST the bot checks for long breaks starting within the next 60 days. Each break is announced **once**; sent notifications are remembered in a state file.
- Messages are posted via [whatsapp-web.js](https://wwebjs.dev/) — the bot logs in as a linked device of a real WhatsApp number (one-time QR scan).

Long breaks detected for 2026: **Mar 20–22, Apr 3–5, May 1–3, Aug 14–16, Oct 2–4, Nov 7–9, Dec 25–27**.

## Deploy to Render

1. Push this repo to GitHub, then in Render choose **New → Blueprint** and pick the repo ([render.yaml](render.yaml) configures everything). A **paid (starter) plan is required** — the free tier sleeps and has no persistent disk, which would lose the WhatsApp session and miss the daily check.
2. In the Render dashboard set `GROUP_INVITE_CODE` to the WhatsApp group invite link (e.g. `https://chat.whatsapp.com/AbCdEf123`). Alternatively set `GROUP_NAME` to the exact group name if the bot's number is already a member.
3. After the first deploy, open `https://<your-app>.onrender.com/qr` and scan the QR with the phone that owns the bot's WhatsApp number (**WhatsApp → Linked devices → Link a device**). This is needed only once — the session persists on the disk.
4. Verify with `https://<your-app>.onrender.com/status`, then send a test message:
   `curl -X POST "https://<your-app>.onrender.com/test?token=<TEST_TOKEN>"`
   (`TEST_TOKEN` is auto-generated by Render — find it in the service's environment tab.)

## Endpoints

| Endpoint | What it does |
|---|---|
| `GET /` | Health check |
| `GET /status` | Auth state, resolved group, pending notifications |
| `GET /qr` | Shows the login QR code when a scan is needed |
| `POST /test?token=…` | Sends a test message to the group |
| `POST /run?token=…` | Runs the daily check immediately |

## Local development

```bash
npm install
npm test                                  # unit tests for break detection
FAKE_TODAY=2026-09-08 npm run dry-run     # prints what would be sent, no WhatsApp needed
cp .env.example .env                      # then fill in GROUP_INVITE_CODE etc.
npm run start:local                       # real run: scan QR at http://localhost:3000/qr
```

## Updating for a new year

1. `npm run ingest -- <image-of-new-holiday-list> > data/holidays-2027.draft.json`
2. **Review and correct** the draft (OCR isn't perfect), then rename it to `data/holidays-2027.json` and deploy.
